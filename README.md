# World Bank Population & Urban Growth Analysis

Clustering and predictive modelling applied to World Bank population data
across five major economies (China, Germany, USA, India, UK) from 1980–2014.

## What This Project Does
- K-Means clustering (3 clusters) on population and urban growth indicators
- Exponential growth modelling with confidence intervals using SciPy
- Correlation heatmap and normalised data visualisations

## Tech Stack
Python · Pandas · Scikit-learn · SciPy · Matplotlib · Seaborn

## Dataset
World Bank Open Data — population indicators 1980–2014
